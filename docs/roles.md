# Website Roles and Responsibilities

This document outlines the responsibilities assigned to each team member for the website project. It provides clarity on ownership of specific sections, improving collaboration and accountability.

## Team Roles

| Name    | Assigned Section / Responsibility | Description |
|---------|---------------------------------|-------------|
| Nappi   | Index / Home Page               | Responsible for the design, layout, and content of the main landing page. Ensures the homepage is up-to-date and visually consistent. |
| Accolla | General tasks / Various sections | Handles miscellaneous tasks across multiple sections of the site, including minor updates, testing, and coordination between modules. |
| Amos    | Books Catalogue                 | Manages the books catalogue, including content updates, search functionality, and categorization of items. |
| Pare    | Individual Book Pages           | Maintains the detail pages for each book, including descriptions, images, and related metadata. |
| Redin   | User Profile and Shopping Cart  | Oversees the user account management and shopping cart functionality, ensuring data integrity and smooth user experience. |

## Project Objectives

- Create a responsive and user-friendly website for library services.
- Maintain consistency in design and layout across all pages.
- Ensure accurate content in books catalogue and individual book pages.
- Provide seamless user account management and shopping cart experience.

## Guidelines

- Use consistent coding standards across HTML, CSS, and JavaScript.
- All changes should be reviewed before merging into the main branch.
- New features should include basic testing for functionality.
- Documentation should be updated for any major changes in functionality.

## Notes

- Team members are encouraged to communicate via the designated project channels.
- Any issues with assigned sections should be reported immediately.
- Backup copies of important files should be maintained regularly.
